這個分頁只跑在 Relay 電腦上。它讀 Server timeline，自動載入手機正在播的同一支 YouTube，然後讓 Chrome 擴充功能擷取這個分頁的實際輸出。

Waiting for phone timeline 手機開始播放 YouTube 後，這裡會自動找到同一支影片。
Server-side browser player 影片由官方 YouTube IFrame Player API 播放；Relay 只控制 video ID、play / pause / seek。

Live mix balance 只改送進 Relay 的歌曲 / 人聲比例，不影響手機端歌手聽到的 YouTube 音量。

不要靠耳朵猜 Mic gain：跑一次下面的 timing calibration，它會量出麥克風實際電平並直接給你建議值。人聲整體太小就用手機端的 Monitor gain 補，那條在混音之後，不會削波。

Vocal timing calibration 用 6 秒手機喇叭漏進 Mic 的同一段音樂，自動量出 Mic 相對 Desktop Source 晚多少。

先連上手機 Microphone 與 Chrome Source，手機播放中即可校準。

校準時：手機關耳機、開喇叭約 50–70%，6 秒內不要說話。完成後可以戴回耳機正常唱。

負值讓人聲更早，正值讓人聲更晚；自動校準完成後通常只需要很小的微調。

Chrome capture 在這個分頁按 Relay 擴充功能圖示。連上後，它會把 tab audio 轉成 PCM 丟回本機 Relay。
