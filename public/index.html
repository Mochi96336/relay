Audio comparison
Voice delay compensation (now / target)
—When the target changes, the current value approaches it gradually to avoid an abrupt shift.

At Mic start: test tone

State
—When the Mic starts, a test tone measures the Mic path and the song path separately.
Test tone detection
—How clearly the tone was detected in the recording; closer to 1 is clearer.
Path difference
—The Mic path delay minus the song path delay.
Test tone result
—The path difference plus the current Robot player position.

During playback: content comparison

State
—Compares the Mic recording with the song to measure the voice delay. Runs during playback and is computed separately from the test tone at Mic start.
Progress
—Collection progress for the song segments this comparison needs.
Agreeing measurements
—A result is used only after the required number of measurements agree; provisional means the first one is applied meanwhile.
Measured delay
—The voice delay measured by this comparison.
Confidence
—Closer to 1 is more reliable.
Levels
—Both sides need sufficient level for comparison.
Segment delays
—Delays measured per segment in this comparison; a large spread indicates an unstable result.

After calibration: ongoing validation

Validation state
—After calibration, the delay is measured again periodically during playback; it updates only after two consecutive measurements agree on a new delay.
Last validation
—The last measured delay, its difference from the value in use, and the verdict.
