RELAY / AUDIO PROTOTYPE

Phone mic → mixer

手機 YouTube 留在本機播放；Relay 讀它的媒體時間，Server 可以用同一條 timeline 驅動自己的測試 backing。YouTube 音訊本身不會被擷取或送到 Server。

Idle
YouTube monitor 播放器完整保留在手機頁面。Relay 只讀播放狀態與媒體時間，不擷取 YouTube 音訊。

Load a video, tap Play in the YouTube player, then start Microphone.

Server backing follower Server 依照 YouTube timeline 產生一條可聽的 timecode 測試音。它不是 YouTube 音訊，也不需要先開 Microphone。

先在手機 Load 並播放 YouTube。

最簡單測法：電腦先按 Monitor；手機播放 YouTube 後按 Start follower。Pause / buffering 時 Server 測試音會停，Resume 會繼續，Seek 會跳到新的 timecode 位置。

Solo recording 電腦端直接錄下 Server 輸出，不包含本機 Monitor gain；講完可以立刻回放。

手機開 Microphone 後，電腦直接按 Record 就能單人測試。

Download recording
Legacy click sync test 保留原本的 120 BPM 工程測試；現在不用優先碰它。

這組 gain / offset 目前仍只作用於舊 click mixer；Server backing follower 先單獨驗證 backing 跟 timeline 的行為。

手機麥克風需要 HTTPS。YouTube monitor 與 Server backing follower 是兩條不同音源：YouTube 只在手機本機播放，Server 只接收 timeline telemetry。
