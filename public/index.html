RELAY / AUDIO PROTOTYPE

Phone mic → mixer

第二階段加入 Server 端測試伴奏、人聲 offset 與單人錄音。仍然沒有 Discord，也還沒有 YouTube。

Idle
Solo recording 電腦端直接錄下 Server 輸出，不包含本機 Monitor gain；唱完可以立刻回放。

手機開 Microphone 後，電腦直接按 Record 就能單人測試。

Download recording
Sync test 手機與 Server 各自播放 120 BPM click；對著手機 click 拍手或說「搭」。

人聲聽起來比 click 晚，就往負值調；比 click 早，就往正值調。Server 保留 800 ms safety buffer，所以可即時前後移動。

手機麥克風需要 HTTPS。單人測試可以不開 Monitor，直接錄完再聽；Sync test 時手機請戴耳機，避免 click 被麥克風直接收到。
