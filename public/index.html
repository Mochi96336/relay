Load a video, tap Play in the YouTube player, then start Microphone.

Desktop YouTube source 電腦另外開一個 Source 分頁，它會自動跟手機的 video / play / pause / seek。Chrome 擴充功能只擷取這個分頁。

這顆按鈕固定開本機 localhost:3000，不會再跟著 Cloudflare 網址走。手機開始播放後：Open source → Enable source audio → 在 Source 分頁點 Relay Tab Audio Source 擴充功能。

Take recording Relay 直接把 authoritative 48 kHz mono mix 寫成 WAV；手機只送 Start / Stop，不再下載整份 PCM 或即時編碼錄音。
